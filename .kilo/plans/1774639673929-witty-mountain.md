# CloudPulse Monitor Frontend Revamp Plan

## Goal
Revamp the CloudPulse Monitor frontend with a modern, beautiful, and responsive UI while maintaining Vue 3 + Tailwind CSS v4 + Vite.

## Requirements
- Use Tabler webfont icons (already loaded via CDN)
- Minimize external dependencies (remove axios, date-fns, npm-run-all; keep chart.js + vue-chartjs)
- Use Pinia for state management
- Use Vue Router
- Use TypeScript (as long as it doesn't complicate things)
- Use pnpm as package manager
- Implement collapsible sidebar navigation (like modern SaaS apps)
- Implement full dark mode with system preference detection
- Keep chart.js for Reports view

## Notes

- Backend runs on port 8080 (Spring Boot)
- API base URL should be configurable (use Vite env vars)
- All timestamps from backend are ISO 8601 strings (OffsetDateTime)
- Idempotency key header: `X-Idempotency-Key` for POST requests
