# Technology Stack

## Frontend
- **Framework**: Vue 3.5.31 (Composition API)
- **Language**: TypeScript
- **Styling**: TailwindCSS 4.2.2
- **Build Tool**: Vite 8.0.3
- **HTTP Client**: Axios

## Backend (Planned)
- **Framework**: Java Spring Boot 4.0.x
- **Language**: Java 25 (Latest LTS)
- **Build Tool**: Gradle / Maven (To be decided, wrapped in monorepo)

## Infrastructure & Tooling
- **Package Manager**: pnpm (for frontend and node scripts)
- **Containerization**: Docker, Docker Compose
- **Database**: SQLite (Current) / PostgreSQL (Under consideration)
- **Observability**: OpenTelemetry (Planned)
